NexOS

Voice-Controlled · Gaming-Native · One Interface. Nothing Else.

Core Design Rule: NexOS runs exactly one graphical interface — the NexOS Shell. No GNOME. No KDE. No login manager. No desktop icons. No menus. The OS is operated entirely through voice and natural language. Apps, settings, and terminals are launched into this single shell on demand — then dismissed.

01 — Single Shell Rule

Everything Removed. One Shell Remains.

🚫
Zero Redundant GUI Surfaces
Pop!_OS is used as the base for its kernel, driver tooling, and APT ecosystem — not its desktop. GNOME Shell, GDM login manager, and every other visual layer are purged during post-install. Everything else is invisible unless asked for by voice.

nexos-strip.sh — Purge all GUI layers after Pop!_OS base install 
#!/bin/bash
# ── Step 1: Remove GNOME desktop and display manager ──────────────────
apt remove --purge -y \
    gnome-shell gnome-session gdm3 gnome-control-center \
    gnome-settings-daemon nautilus gnome-terminal \
    gnome-software gnome-shell-extensions ubuntu-desktop \
    pop-desktop pop-gnome-shell-theme

# ── Step 2: Remove Xorg (Wayland-only system) ─────────────────────────
apt remove --purge -y xorg xserver-xorg xserver-xorg-core
# XWayland available if ANY legacy app requires it (opt-in only)

# ── Step 3: Mask every display manager permanently ────────────────────
systemctl disable --now gdm3 lightdm sddm 2>/dev/null
systemctl mask gdm3 lightdm sddm

# ── Step 4: Auto-login straight to TTY1 → NexOS Shell ────────────────
mkdir -p /etc/systemd/system/getty@tty1.service.d/
cat > /etc/systemd/system/getty@tty1.service.d/autologin.conf <<EOF
[Service]
ExecStart=
ExecStart=-/sbin/agetty --autologin nexos --noclear %I \$TERM
EOF

# ── Step 5: Start Hyprland shell on TTY1 login ────────────────────────
echo '[[ -z $DISPLAY && $XDG_VTNR -eq 1 ]] && exec Hyprland' >> /home/nexos/.bash_profile

# ── Step 6: Clean up ──────────────────────────────────────────────────
apt autoremove --purge -y && apt clean
echo "Done. NexOS Shell is the only GUI. Reboot to apply."

04 — Voice Engine

Voice Processing Pipeline

STEP 01
Wake Word
Porcupine listens always-on. "Hey Nex" triggers pipeline. Fully on-device. <5ms.
STEP 02
Speech → Text
Whisper.cpp converts audio offline. Tiny model for speed, large model for accuracy.
STEP 03
NLU Parse
Rhasspy maps utterance to intent + slots. "launch Steam" → {intent: app.open, app: steam}
STEP 04
Dispatch
Routes to shell command, D-Bus call, Flatpak launch, plugin hook, or system action.
STEP 05
TTS + Visual
Piper TTS speaks brief confirmation. Optional HUD pulse. App window appears in shell.

09 — Extensibility

Plugin Architecture

STEP 01
Manifest
JSON descriptor defines voice intents, permissions, D-Bus events, and surface type.
STEP 02
Intent Register
Plugin registers commands with Rhasspy. New voice phrases become active immediately.
STEP 03
Event Bus
Subscribe to system events: game start/end, GPU temp, app open, volume change via D-Bus.
STEP 04
Sandbox Exec
Logic runs in isolated Python/Node runtime with scoped capabilities only.
STEP 05
Shell Surface
Output via Hyprland overlay, TTS voice, dock badge, or silent background action.
